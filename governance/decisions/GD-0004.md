# GD-0004: Clarification (proposed): model identifiers and attribution trailers

- **Decision ID:** GD-0004
- **Date:** 2026-11-07
- **Status:** PROPOSED. Not ratified. Takes effect only on the owner's ratification.
- **Kind:** clarification of how two standing instructions interact. It changes no ratified rule.
- **Limitation:** single steward. `C-DUAL-001` is open.

## Context

Two standing instructions conflict. The coding environment's standing rule says repository artifacts
must not contain model identifiers. A separate attribution note asked for co-author trailers that
name a model. Earlier commits in this repository carry such trailers from before this clarification.

## Proposed clarification

1. **The prohibition takes precedence.** Do not add model names to commit trailers, decision records,
   specifications, or other repository artifacts to satisfy an attribution convention.
2. **Attribution is kept through roles and provenance**, not model names:
   - *decision steward*: the named person who ratified or approved the decision;
   - *implementation author*: identified by the coding session URL;
   - *reviewer*: named only where a named human actually reviewed the change;
   - *commit SHA* and *verification evidence*.
3. **Never imply an independent reviewer** where none participated. Where no human reviewed a change,
   say so.
4. **Historical commits are not rewritten.** Earlier trailers stay as they are, and this record does
   not reinterpret them.

## Effects

None on evidence, witness, or authority. No contradiction is opened or closed.
