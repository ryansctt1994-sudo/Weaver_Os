# E3.5 Reproduction Kit Specification

**Status:** SPECIFICATION — IMPLEMENTATION INCOMPLETE  
**Purpose:** Independent reproduction without interpretation drift  
**Authority:** Required before E3.5 promotion

## Purpose

This specification defines the intended independent reproduction procedure for the Weaver governance spine. It does **not** claim that the current `make verify-e35` implementation already performs every step below.

The intended end state is that an independent operator can rebuild the qualified environment, replay the canonical `authority_ledger.json`, derive the chain head and runtime state digest from execution, and attest to the result without founder intervention.

## 1. Binding semantics

The manifest uses separate identities:

- `source_base_commit` — the exact predecessor/source commit whose ledger and spine state were used to derive the manifest.
- `release_commit` — an optional external release/commit binding. A manifest cannot reliably self-bind the commit that contains itself; null means this binding is not yet established.
- `authority_ledger_hash` — canonical digest of the ordered ledger.
- `expected_head_hash` — head derived from the ordered ledger chain.
- `expected_state_digest` — runtime-derived state digest only when the runtime actually computes one.
- `docker_image` — null unless a concrete image has been built and bound.

A declared environment is not a replayed environment:

```text
DECLARED_NOT_REPLAYED != REPLAYED
```

## 2. Current implemented boundary

At the time of manifest v1.1:

- `tools/fail_closed_spine.py` computes the canonical ledger digest and ordered chain head locally.
- The current `verify_attestations.py` still uses pinned constants for head/state values and is therefore not accepted as independent computation.
- No runtime-derived `STATE_DIGEST` is currently qualified.
- No Docker image is claimed.
- No independent witness is claimed.

Therefore the current `verify-e35` path is expected to remain **red** after manifest correction until verifier/runtime gaps are separately repaired.

## 3. Intended reproduction procedure

1. Check out the externally bound release commit or release artifact.
2. Verify the manifest digest.
3. Verify the canonical authority-ledger digest.
4. Derive the ordered chain head from ledger contents.
5. Rebuild the qualified execution environment from frozen dependency inputs.
6. Replay the ledger through the actual runtime when that runtime is available.
7. Derive `STATE_DIGEST` from runtime state, not from a pinned constant.
8. Compare all derived values to the manifest.
9. Archive raw stdout/stderr, exit code, environment identity, and witness identity.

## 4. Failure conditions

- **Exit 0:** all required implemented predicates for the requested qualification scope pass.
- **Exit 1:** derived value mismatch or a required qualification predicate is unearned.
- **Exit 2:** missing/malformed artifact.
- **Exit 3:** attestation signature verification failure, where signatures are actually part of the requested scope.

A partial/local verifier must not return E3.5 success merely because a field is present.

## 5. Witness rule

A local author execution does not cross the independent reproduction boundary.

```text
CrossHostSameOperator != IndependentOperatorReproduction
```

Independent promotion requires a separately identified operator/environment and artifact-bound raw outputs under the frozen protocol.

## 6. Promotion boundary

No result here changes authority.

```text
Specification != LocalRun != IndependentReproduction != Authority
```

W0, O0 WITHHELD, and production prohibited remain unchanged until separately governed transitions are earned.
