# E3.5 Reproduction Kit Specification

**Status:** SPECIFICATION — IMPLEMENTATION INCOMPLETE  
**Purpose:** Independent reproduction without interpretation drift  
**Authority:** Required before E3.5 promotion

## Purpose

This specification defines the intended independent reproduction procedure for the Weaver governance spine. It does **not** claim that the current `make verify-e35` implementation already performs every step below.

The intended end state is that an independent operator can replay a frozen release artifact in a qualified environment, derive the chain head and runtime state digest from execution, and attest to the result without founder intervention.

## 1. Binding semantics

The manifest separates:

- `source_base_commit` — exact predecessor/source commit used to derive the manifest;
- `release_commit` — externally bound release/commit identity;
- `authority_ledger_hash` — canonical digest of the ordered authority ledger;
- `expected_head_hash` — ordered ledger-chain head;
- `expected_state_digest` — a digest whose class is named by `state_digest_status`;
- `state_digest_method` — exact derivation method;
- `docker_image` — null unless a concrete image is built and bound.

A declared environment is not a replayed environment:

```text
DECLARED_NOT_REPLAYED != REPLAYED
```

A local reference reducer is not runtime replay:

```text
LOCAL_REDUCER_COMPUTED != COMPUTED_FROM_RUNTIME
```

## 2. Current implemented boundary

The current local spine can:

- derive the canonical authority-ledger digest;
- derive the ordered ledger chain head;
- replay the six admitted `STATE_TRANSITION` events through
  `authority-transition-reducer-v1`;
- derive the bounded local state projection
  `{"receipt_id":"AL-ADOC-2026-001","state":"EXECUTED"}`;
- derive local state digest
  `39a5996b1bba7a0ed4f0a5c549ad58af5300b5abb5890ddf9eb47c9d039c5a0e`.

This is classified:

```text
LOCAL_REDUCER_COMPUTED
```

not:

```text
COMPUTED_FROM_RUNTIME
```

No concrete release commit, replay-qualified environment, Chronicle/Raft runtime
state digest, or independent reproduction is currently claimed.

## 3. Intended reproduction procedure

1. Obtain an externally bound release commit or release artifact.
2. Verify release identity independently of mutable in-package declarations.
3. Verify manifest digest.
4. Verify authority-ledger digest.
5. Derive the ordered chain head from ledger contents.
6. Build the frozen execution environment.
7. Replay the ledger through the actual qualified runtime.
8. Read/derive the runtime state projection under a frozen runtime-state contract.
9. Compute `STATE_DIGEST` from that runtime projection.
10. Compare runtime-derived state against the bounded reference projection where applicable.
11. Archive raw stdout/stderr, exit code, environment identity, release identity, and witness identity.

## 4. Failure conditions

- **Exit 0:** every required predicate for the requested qualification scope passes.
- **Exit 1:** a derived value mismatches or a required qualification predicate is unearned.
- **Exit 2:** artifact or schema malformed/missing.
- **Exit 3:** signature verification failure when signatures are part of the requested scope.

A local verifier must not return E3.5 success merely because a field is present.

## 5. Witness rule

```text
CrossHostSameOperator != IndependentOperatorReproduction
```

Independent promotion requires a separately identified operator/environment and
artifact-bound raw output under the frozen protocol.

## 6. Promotion boundary

```text
Specification != LocalMechanics != LocalReducerReplay
!= RuntimeReplay != IndependentReproduction != Authority
```

W0, O0 WITHHELD, and production prohibited remain unchanged until separately governed transitions are earned.
