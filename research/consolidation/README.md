# Source preservation boundary

The snapshots are original Git archives at commits recorded in
`docs/consolidation/source-manifest.json`. They retain original MIT notices and
historical tests, including known-vulnerable baselines. They are data for review,
not installed packages or a second runtime. Runtime imports from research,
evidence, legacy, archive and tools are refused by the trust-domain checker.

Use the live integrated tooling and Weaver's protected owner for new work.
Do not activate archived hooks or execute archived tool registries as a security
boundary. Gate deployment, key custody and independent reproduction are not
established by archive integrity or donor test results.
