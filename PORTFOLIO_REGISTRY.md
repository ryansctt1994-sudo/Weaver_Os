## Fork policy

Forks are preserved as upstream-derived work unless commit-level evidence establishes a local contribution. Their presence may support comparison, experimentation, integration, or collaboration, but it must not be counted as original implementation by default.

When local fork work becomes important, record:

1. upstream parent and base commit;
2. local commit range;
3. files changed locally;
4. license obligations;
5. tests run against the local delta;
6. whether the fork is a dependency, experiment, or candidate for extraction into an original repository.

## Registry rule

```text
PROVENANCE FIRST.
EVIDENCE STAYS LOCAL TO THE ARTIFACT THAT EARNED IT.
NO FORK INHERITS PORTFOLIO AUTHORITY.
NO PORTFOLIO REPO INHERITS UPSTREAM AUTHORSHIP.
```
