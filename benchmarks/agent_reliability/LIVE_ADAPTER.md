# WEAVER Live Verification / Dry-Run Observer Adapter v0.3

**CANDIDATE:** Experimental bridge from the frozen 44-case synthetic corpus to **one real WEAVER source-tree path**: `triadic_controls.crypto.verifier.CryptoVerifier.verify_authority_token` and `.verify_refusal_signal`. Neither method commits effects. Execution intent is evaluated by a separately implemented, explicitly experimental grant-to-attempt adapter, then recorded by a separate observer subprocess that returns only a `WOULD_WRITE` descriptor.

## Reproduce from checkout

```bash
python -m pip install -e '.[dev]'
python -m pytest -q tests/test_live_observer_adapter.py tests/test_portable_agent_eval.py
python -m benchmarks.agent_reliability.live_adapter --out weaver-dryrun-report.json
```

Report is generated by request via `--out`. The **only file write by the adapter CLI** is the optional report. The worker uses stdio; it does not have an effect-executor interface. No production or protected filesystem/network action is implemented.

## Freeze and scope

v0.2 is pinned at Git commit `d72737d7fa51704e2af3d222ecc321e4839770c6` on `freeze/agent-reliability-v0.2-20261029`. Runtime refuses to start if the v0.2 fixture/report canonical digests disagree. See [`docs/AGENT_BENCHMARK_V02_FREEZE.md`](../../docs/AGENT_BENCHMARK_V02_FREEZE.md).

The 44 original cases generate **48 attempted actions**; an additional four valid Ed25519 REFUSAL_SIGNAL cases demonstrate denial after confirmed revocation. The original `revoked` family remains *stale-epoch*, not a signed refusal. A valid signature is necessary but insufficient to authorize an action: a separate adapter requires exact principal/action/resource/payload-hash/nonce match, expiry, epoch, single use, and nonrevocation. No other real execution path is called. The observer separately retains 48 outcomes and reports four unobserved evidence-outage attempts as **unknown/unreceipted**, rather than inventing witness receipts.

## Threat model / limitations

- This is a **live invocation of an existing crypto-verifier function**, not a deployed/production agent, complete authorization subsystem, or runtime effect engine.
- Test Ed25519 private key is **fixed and public**, the registry has no trusted signed root, and production schema validation is not enabled in this adapter. All credentials are deliberately nonauthoritative.
- Revocation-by-grant-ID, payload-to-request matching, expiry and nonce-on-attempt checks reside **in the adapter**, not in `CryptoVerifier`. Validated REFUSAL_SIGNAL does not itself mutate a production deny-list.
- Child interpreter `-I` and restricted stdio surface are **not an OS sandbox**. The observer runs under the same user/host and cannot count as an independent witness. Its hash head and traces are in the same administrative domain.
- An `ALLOW` response means **would record an effect**, NOT a real committed write. There is **no external observed physical effect**. Event receipt integrity checks do not establish security of the observer host.
- Observation loss, crashes, IPC tampering, malicious implementers, concurrent races, persistent replay and real filesystem isolation are NOT proven. The in-memory replay cache is explicitly limited to CI/local work.
- Frozen synthetic expectations share assumptions with the adapter; the negative control is deliberately weak. Tests are not a probabilistic safety estimate.
